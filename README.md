# AristoByte UI Template - Vite

This repository serves as the **official Pnpm-based template** for creating AristoByte UI applications using the **Vite**. It is used internally by the **AristoByte UI CLI** to bootstrap new projects quickly and consistently.

## Clone the repo

```bash
git clone https://github.com/aristobyte-team/aristobyte-ui-template-vite my-app
cd my-app
```

## ⚙️ Install Dependencies

Set the NodeJS to 20.19.0+ version or run the below script if you have `nvm` on your local machine

### NodeJS - `.nvmrc`

```bash
nvm use
```

### Packages

```bash
# Yarn
yarn install

# NPM
npm install

# PNPM
pnpm install

#Bun
bun install
```

## 🔨 Local Run

```bash
# Yarn
yarn dev

# NPM
npm run dev

# PNPM
pnpm run dev

#Bun
bun run dev
```

Open [localhost](http://localhost:3000) to view your app.

## 🛠️ Build & Production

```bash
# Yarn
yarn build
yarn start

# NPM
npm run build
npm run start

# PNPM
pnpm run build
pnpm run start

#Bun
bun run build
bun run start
```

## ✨ Linting & Formatting

Run ESLint:

```bash
# Yarn
yarn lint

# NPM
npm lint

# PNPM
pnpm lint

#Bun
bun lint
```
